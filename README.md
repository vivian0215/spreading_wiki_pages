# KSP Spreading Wiki — Public Pages

Public-facing, sanitized presentation layer for the KSP / Automated Financial Statement Spreading project.

## Purpose

This repository is intentionally separated from the private `spreading_wiki` knowledge repository. It contains only content considered suitable for public GitHub Pages publishing.

## Security boundary

Do not place the following in this repository:
- customer/CIF-level data
- internal credentials, tokens, endpoints, or secrets
- detailed internal API specifications
- confidential architecture diagrams
- employee-identifying audit details
- raw SharePoint paths or source documents
- internal requirement wording unless explicitly approved for public release

## GitHub Pages

This repository is designed to publish directly from the `main` branch at repository root.

Expected URL after Pages is enabled:

`https://vivian0215.github.io/spreading_wiki_pages/`

## Relationship to the private repository

The private repository remains the project second brain and source of truth. This public repository is a sanitized read-only presentation layer only.
